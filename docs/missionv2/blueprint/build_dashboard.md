# Build Dashboard: Product Specification

---

## Overview

The Build Dashboard is the **command center** for Mission 5. It's where users stop planning and start building. Instead of jumping between spreadsheets, to-do lists, and notes, everything they need is in one place.

**The Core Promise:** "Stop planning. Start building. Track everything in one place."

---

## Philosophy: Why This Dashboard Exists

### The Problem We're Solving

First-time founders face three big problems during the build phase:

| Problem | What It Looks Like | How the Dashboard Solves It |
|---------|-------------------|---------------------------|
| **Lack of Focus** | Jumping between tasks, not knowing what to do next | One-page overview shows exactly what needs attention |
| **Losing Momentum** | Starting strong, then fading after a week | Daily build logs + progress bars keep the streak alive |
| **Losing Sight of the Goal** | Building features nobody asked for | POC checks and feature tracking keep you anchored to the MSP |

### The User Journey

The dashboard is designed for one user journey: **build something real, get it in front of real people, and launch.**

```
Day 1-7:   Set up tasks, start building, log daily progress
Day 8-14:  Build the core, track costs, reach POC milestone
Day 15-21: Get testers, collect feedback, validate
Day 22-30: Make final tweaks, launch checklist, GO!
```

## The 6 Tabs: A Tour

### Tab 1: Overview (The "Pulse Check")

**What it does:** Gives users a 5-second status update on their entire build.

**Why it matters:** Most founders open their dashboard and feel overwhelmed. Overview solves this by showing only what matters.

**What they see:**

**1. Four Metric Cards (The "Vital Signs")**

| Card | What It Shows | Why It Matters |
|------|---------------|----------------|
| **Progress** | Overall build % + days left | "Am I on track?" |
| **Tasks** | Completed / Total + blocked | "What's holding me back?" |
| **Budget** | Spent / Total + remaining | "Am I burning through cash?" |
| **POC Status** | ✅ Ready or ⏳ Building | "Can I start testing yet?" |

**2. Quick Actions (The "What Now?" Button)**

Three buttons that answer the most common question: "What should I do right now?"

- **+ Add Task** → Add a new task without leaving the page
- **📅 Log Hours** → Track time spent (builds accountability)
- **📤 Share Log** → Post progress to social media (builds external accountability)

**3. Recent Activity Feed**

A timeline of what's happened recently. This builds momentum—seeing progress makes users want to keep going.

```
✅ Completed: "Set up landing page" (2 hours ago)
🔄 Started: "Build prototype" (1 day ago)
📝 Logged: "5 hours on MVP" (2 days ago)
```

**4. Weekly Focus**

A single sentence that users set for themselves at the start of each week. This keeps them anchored.

```
This week's focus: "Complete prototype by Friday"
[Update Focus]
```

---

### Tab 2: Tasks (The "Build Board")

**What it does:** Manages everything that needs to be built, in one simple board.

**Why it matters:** Most founders use scattered to-do lists. This board shows exactly what needs to be done, what's in progress, and what's done.

**What they see:**

**1. Four Columns (The Kanban Board)**

| Column | What Goes Here | When to Use |
|--------|---------------|-------------|
| **To Do** | Tasks not yet started | "I know I need to do this" |
| **In Progress** | Tasks being worked on | "I'm actively building this" |
| **Done** | Completed tasks | "This is finished" |
| **Blocked** | Tasks stuck | "I can't move forward until X happens" |

**2. Task Cards**

Each task shows:

- **Priority Color** → Red (High) / Yellow (Medium) / Green (Low)
- **Title** → What needs to be done
- **Due Date** → When it needs to be done
- **Tags** → Categorization (e.g., "MVP", "Design", "Core")
- **Dependency Count** → "2 tasks must be done first"

**3. How to Use It**

- **Add a task** → Click "Add Task" → Fill in title, description, due date
- **Move a task** → Drag it from one column to another
- **Edit a task** → Click on any card → Opens detail view
- **Filter tasks** → Search or filter by priority, milestone, or tags

**4. Auto-Generated Tasks**

The dashboard creates tasks automatically from:

- **Features marked "Must Have"** → Each becomes a task
- **Milestones** → Each milestone creates sub-tasks
- **Past missions** → Anything from Missions 1-4 that needs action

This means users don't start from a blank slate—they already have a ready-to-go checklist.

- **Today's date** → A vertical line showing where they are

- **Progress bar** → How much of the timeline is complete

## The Core Experience: How It All Works Together

### The Daily Routine

When users open the dashboard, they follow a simple routine:

1. **Look at Overview** → "Where am I?"
2. **Check Tasks** → "What's next?"
3. **Log what they did** → "I built X today"
4. **Update progress** → "I'm Y% done"

This 5-minute check-in builds the habit of showing up every day.

### The Weekly Reset

Every week, users should:

1. **Check the timeline** → "Am I on track?"
2. **Review budget** → "Am I spending too much?"
3. **Set weekly focus** → "What will I build this week?"

### The Tester Loop

When the POC is ready, users shift to the testing loop:

1. **Recruit testers** → Find 5 people with the problem
2. **Onboard testers** → Give them access and instructions
3. **Collect feedback** → Listen and learn
4. **Iterate** → Make changes based on feedback
5. **Decide** → Launch, iterate again, or pivot

### The Launch Timeline

The final 7-10 days follow a rhythm:

```
Day -10:  Launch checklist → What's missing?
Day -7:   Finish final tweaks → Is it ready?
Day -3:   Prepare announcement → What will you say?
Day -1:   Final review → One last check
Day 0:    LAUNCH! 🚀
Day +1:   First sale celebration 🎉
```

## The Emotional Journey

The dashboard isn't just functional—it's designed to support the founder's emotional journey.

| Phase | What the Founder Feels | What the Dashboard Does |
|-------|----------------------|------------------------|
| **Getting Started** | Overwhelmed, unsure | Auto-generated tasks show them exactly what to do |
| **Mid-Build** | Tired, losing momentum | Progress bars show they're making progress |
| **Testing** | Nervous, uncertain | Feedback from real people builds confidence |
| **Pre-Launch** | Scared, anxious | Checklist reduces anxiety—every check is a win |
| **Launch** | Excited, proud | The dashboard celebrates their achievement |

## What's Not Included (On Purpose)

| Feature | Why It's Not Here |
|---------|-------------------|
| **Complex collaboration** | This is for solo founders first. Adding teams adds complexity. |
| **Detailed analytics** | First-time founders don't need analytics—they need to launch. |
| **Advanced reporting** | Reports are for investors. This is for builders. |
| **Integration overload** | Too many integrations = distraction. We start with essentials. |
| **Custom workflows** | Simplicity > Flexibility. We give one way that works. |
