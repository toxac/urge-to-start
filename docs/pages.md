# Program Pages

## Routes
- app/(platform)/program 
    - page.tsx -> main program page (we will implement this last in sequence)
    - /missions/
        -[id]/page.tsx -> mission deatils page
        - /quests/
            - [id]/page.tsx -> quest detail page
## Key elements of the app
- Designed as mission and quests
- missions have broad goal such as "finding right opportunity"
- mission has quests which are parts which would let user achieve the goals. Quest for example could be different approach to finding business opportunity ( your problems, observing people around you, looking for trends and patterns)
- each quest has tasks which are clear and single focus actions. task could be auditing your daily life and identifying point of friction, frustation, despair etc
- pages
    - Mission - has a page which outlines the goal
    - quest has a page and the tasks are part of this page, this is like the action control center

## Core Philosophy and Approach
1. Designed for action
    - minimum cognitive load
    - design built with affordances
    - focus on next action rest should either be hidden/collapses or out of focus
    - consistent design language on pages
